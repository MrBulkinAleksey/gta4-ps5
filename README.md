# GTA IV for PS5

A PS5 homebrew port of Grand Theft Auto IV (Xbox 360), built on
[Liberty Recompiled](https://github.com/OZORDI/LibertyRecomp) by OZORDI and
[LibertyRecompAndroid](https://github.com/vaduur/LibertyRecompAndroid) by vaduur.

Version 1.0, in testing (1.0 Test 2). PS5 port by [@elripalda](https://www.elripalda.com).

This repo holds the PS5 port: `setup.sh` gets the Liberty Recompiled source
it's built on and applies `patches/liberty-ps5.patch`, and `ps5/` is the PS5
build, packaging and hub. Build steps are in [ps5/BUILD.md](ps5/BUILD.md).

No game files are included. You need your own copy of GTA IV for Xbox 360.
